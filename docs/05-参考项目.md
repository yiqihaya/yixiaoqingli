## 主要参考项目

### 1. Open-LLM-VTuber ⭐ 3,000+
- **GitHub**：[Open-LLM-VTuber/Open-LLM-VTuber](https://github.com/Open-LLM-VTuber/Open-LLM-VTuber)
- **用途**：Live2D + LLM + TTS 完整架构参考
- **参考价值**：
  - Live2D 表情与情感联动的实现方式
  - System Prompt 设计
  - 语音打断（voice interruption）机制
- **技术栈**：Python, Live2D, 多种 LLM/TTS 支持

### 2. Project AIRI ⭐ 14,300+
- **GitHub**：[moeru-ai/airi](https://github.com/moeru-ai/airi)
- **用途**：浏览器端 AI 伴侣 PWA 架构参考
- **参考价值**：
  - PWA 架构设计
  - Live2D 在浏览器中的最优实践
  - 多平台兼容（Web, Discord, Telegram）
- **技术栈**：TypeScript, WebGPU, Web Workers

### 3. live2d-website
- **GitHub**：[pleasureswx123/live2d-website](https://github.com/pleasureswx123/live2d-website)
- **用途**：React + Live2D 集成直接参考
- **参考价值**：
  - React 19 + TypeScript + Vite 架构
  - pixi.js + pixi-live2d-display 集成
  - 唇形同步（lip-sync）
  - 表情/动作控制系统
- **技术栈**：React 19, pixi.js, pixi-live2d-display, Zustand

### 4. react-live2d-starter
- **GitHub**：[AkHiL667/react-live2d-starter](https://github.com/AkHiL667/react-live2d-starter)
- **用途**：Live2D React 快速启动模板
- **参考价值**：
  - `<Live2DCharacter />` 组件封装
  - 模型热切换
  - Vite 配置参考
- **技术栈**：React, Vite, Cubism SDK

### 5. fount ⭐ 700+
- **GitHub**：[steve02081504/fount](https://github.com/steve02081504/fount)
- **用途**：AI 角色交互框架
- **参考价值**：
  - 角色卡系统（Character Card）
  - 人设 Prompt 管理
  - 多角色对话
- **技术栈**：Deno, Express
