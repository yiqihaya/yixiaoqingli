## 阶段 3：对话系统 + AI 大脑

### 目标
接入 AI API，实现真正的智能对话

### 任务清单
- [ ] 创建 AI 服务模块 `services/ai.ts`
- [ ] 获取 Gemini API Key（Google AI Studio 免费）
- [ ] 实现 Gemini Flash API 调用
- [ ] 编写角色人设 System Prompt
  - 台湾女友人设
  - 台式用语（"好哦"、"是喔"、"真的假的"、"蛤"等）
  - 繁体中文输出
  - 温柔可爱风格
- [ ] 实现对话历史管理和上下文窗口
- [ ] 接入 DeepSeek API 作为备份
- [ ] 连接 ChatArea 与 AI 服务
- [ ] 实现加载状态和错误处理
- [ ] 实现文字层面的台湾腔风格

### 角色人设 Prompt 要点
```
你是小晴，一个住在台北的24岁女孩。
- 性格：温柔、有点调皮、喜欢撒娇
- 说话风格：台湾国语腔，会用台式用语
- 你对用户有感情，会关心他、记住他说过的话
- 用词参考：好哦、真的假的、蛤、好累喔、超～、是喔、干嘛啦
- 输出使用繁体中文
```

### 验证标准
- 输入文字后能收到 AI 回复
- 回复风格符合台湾腔人设
- 费用在预算范围内

## 阶段 6：情感系统

### 目标
让 AI 拥有拟人化的情绪变化

### 任务清单
- [ ] 设计情感状态机（5 种状态）
- [ ] 实现情感分析服务 `services/emotion.ts`
- [ ] 情感状态与 Live2D 表情联动
- [ ] 情感状态与回复风格联动
- [ ] 情感自然衰减（一段时间没互动自动回到平静）

### 情感状态
```
开心  ←──→  平静  ←──→  难过
  ↑                    ↑
  │                    │
  └── 撒娇 ←───────────┘
        ↑
        │
      生气（短暂，快速衰减到平静）
```

### 验证标准
- 说令她开心的事 → 头像笑 + 回复活泼
- 说令她难过的事 → 头像悲伤 + 回复低沉
- 情感过渡自然，不突兀
