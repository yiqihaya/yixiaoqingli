## 技术选型

### 前端框架：React 19 + TypeScript
- **选择理由**：生态最丰富，PWA 支持好，社区活跃
- **类型安全**：TypeScript 减少运行时错误
- **React 19**：最新版本，支持 React Server Components 等新特性

### 构建工具：Vite
- **选择理由**：极快的 HMR（热更新），开发体验好
- **PWA 插件**：`vite-plugin-pwa` 成熟稳定

### 样式方案：Tailwind CSS
- **选择理由**：原子化 CSS，开发速度快，响应式友好
- **Apple 风格**：通过自定义配置实现 iOS 风格的圆角、阴影、毛玻璃

### 动画方案：Framer Motion
- **选择理由**：React 生态最好的动画库，API 简洁
- **手势支持**：拖拽、点击反馈等

### Live2D 渲染：pixi-live2d-display
- **GitHub**：[github.com/guansss/pixi-live2d-display](https://github.com/guansss/pixi-live2d-display)
- **选择理由**：最成熟的 Web Live2D 渲染库，支持 Cubism 2/3/4/5
- **底层**：基于 PixiJS，性能好
- **替代方案**：easy-live2d（更简单的 API）

### AI 对话：Gemini Flash + DeepSeek
- **Gemini Flash**：Google 免费方案，每天 1500 请求，作为主力
- **DeepSeek V3**：国内便宜，¥2/百万输入 tokens，作为备份
- **接入方式**：直接 HTTP fetch 调用 REST API

### 语音识别：Web Speech API
- **选择理由**：浏览器内置，零成本，无需额外依赖
- **Android Chrome**：完整支持
- **fallback**：whisper.cpp WASM（更准但更重）

### 语音合成：Web Speech Synthesis
- **选择理由**：浏览器内置，支持 zh-TW
- **限制**：声音可能不够自然，先尝试再评估

### 本地存储：Dexie.js（IndexedDB 封装）
- **选择理由**：IndexedDB 是浏览器端唯一的大容量存储方案
- **Dexie.js**：提供了 Promise 友好的 API
